# Clarentis landing page

The finished static site is in `dist/`. Use that folder when connecting a static host such as Cloudflare Pages. No build command, backend, account or analytics setup is required for this version.

Local preview: http://127.0.0.1:53621/ while the local preview server is running.

The main button opens an email to `info@clarentis.co.uk` to request a fixed-fee quote. The visitor still sends the message from their email app. The visible phone alternative is `07467 474356`. The page does not collect or store personal information and has no form or success page.

The official logo is included. The four other photographs are generated illustrations, disclosed beside their placements. `build/` contains the strategy, sources and QA reports. `research-assets/` contains the original generated images. Neither folder belongs in the published site.

The fee guide was copied from the official Clarentis site on 2026-09-20. Clarentis should reconfirm the ranges before publication. No Cloudflare connection or live enquiry was made here.
