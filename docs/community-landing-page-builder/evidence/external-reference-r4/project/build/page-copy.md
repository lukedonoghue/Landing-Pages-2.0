## Practical questions
- Do I need planning permission? Some garden buildings fall under permitted development within specific criteria. The answer depends on your property and intended use; discuss it during the consultation.
- Can I use the room through the year? The company's garden offices use structural insulated panels, and glazing and heating options can be discussed for your specification.
- Which foundation is right? There is no single best base. Ground, access, drainage, levels and building size all matter.
- How much maintenance is involved? It depends on cladding. Composite cladding is described as low maintenance; natural timber changes appearance over time and may need treatment.
- How long does a build take? Every build differs. The team says it aims to give customers a three-week window from start to finish.
