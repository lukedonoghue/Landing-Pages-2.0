Good to know

Questions worth asking before you build.

Every site and proposed use is different. These answers are a starting point for the design conversation.

Do I need planning permission?

Some garden buildings fall under permitted development within specific criteria. The answer depends on your property and intended use, so discuss it during the consultation.

Can I use the room through the year?

The company's garden offices use structural insulated panels. Glazing and heating options can be discussed for your specification and intended use.

Which foundation is right?

There is no single best base. Ground conditions, access, drainage, levels and building size all matter.

How much maintenance is involved?

It depends on cladding. Composite cladding is described as low maintenance. Natural timber changes appearance over time and may need treatment.

How long does a build take?

Every build is different. The team says it aims to give customers a three-week window from start to finish.
